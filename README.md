# SEVENS ROGUE v0.1

Pyxel prototype of a single-player roguelite based on Sevens (七並べ).

## Core
- 20 turns
- 5-card hand
- 2 HOLD slots
- FIRE timed reward
- directional board bonuses
- LAST RUSH from turn 16
- target score: 450

## Controls
- Touch/click card: play
- Touch/click HOLD area on a hand card: hold
- Touch/click held card: return it to hand
- Keyboard: 1-5 play, Shift+1-5 hold, Q/W return held cards, R retry
